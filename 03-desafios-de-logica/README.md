# 03 - Desafios de Lógica

Desafios de lógica de programação com matrizes e arrays, usando estruturas de repetição aninhadas e condicionais.

## Tópicos abordados

- Percurso de matrizes com `foreach` aninhado
- Acumuladores e busca de maior valor
- Contagem e localização do primeiro elemento que atende a uma condição
- Validação de dados em matriz
- Busca linear em array

## Desafios

| Nº | Descrição |
|---|---|
| 1 | Matriz 3x3 de quantidades: calcula o total e localiza a maior quantidade, informando linha e coluna |
| 2 | Matriz 5x5 de assentos (0 indica lugar vazio): conta os lugares disponíveis e informa o primeiro lugar vazio |
| 3 | Matriz 3x3 no estilo sudoku: verifica se contém apenas números de 1 a 9, sem repetição |
| 4 | Busca de um valor em um array, informando a posição em que foi encontrado |

As posições são exibidas a partir de 1 (linha 1, coluna 1).

## Como executar

```bash
php index.php
```

O programa não é interativo. Os dados de cada desafio estão definidos em variáveis no próprio `index.php` e podem ser alterados para testar outros cenários.
