# 01 - Introdução e Revisão

Exercícios de revisão dos fundamentos de PHP, com leitura de dados pelo terminal.

## Tópicos abordados

- Entrada e saída no terminal (`readline`, `echo`, `print`)
- Operadores aritméticos
- Estruturas condicionais (`if`, `elseif`, `else`)
- Estruturas de repetição (`while`, `for`, `foreach`)
- Arrays indexados, associativos e multidimensionais
- Funções simples

## Exercícios

| Nº | Descrição |
|---|---|
| 1 | Leitura e exibição de nome e idade |
| 2 | Apresentação com nome, profissão e hobby |
| 3 | Operações aritméticas entre dois números: soma, subtração, multiplicação, divisão e resto |
| 4 | Verificação de maioridade |
| 5 | Classificação de nota em aprovado, recuperação ou reprovado |
| 6 | Tabuada de um número com `while` |
| 7 | Números pares de 2 a 50 com `for` |
| 8 | Números de 1 a 100 classificados como par ou ímpar |
| 9 | Listagem dos elementos de um array de frutas |
| 10 | Array associativo com os dados de um carro |
| 11 | Média de notas por aluno, com array multidimensional |
| 12 | Busca de uma cidade em uma lista com `in_array` |
| 13 | Função para cálculo de média |
| 14 | Função para verificação de idade |
| 15 | Lista de compras preenchida até o usuário digitar `sair` |

## Como executar

```bash
php index.php
```

O programa é interativo: cada exercício solicita os dados pelo terminal, um após o outro.

## Observações

- Todos os exercícios estão em um único `index.php`, separados por comentários.
- As entradas não passam por validação (por exemplo, a divisão por zero no exercício 3 não é tratada), pois o foco da atividade são as estruturas básicas da linguagem.
